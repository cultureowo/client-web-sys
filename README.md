# Study Planner · Лабораторна №8

Планувальник на Vite, React 19 і TypeScript. Стилізація: SCSS + BEM. Адаптивний інтерфейс, світла й темна теми, синьо-фіолетовий градієнт кнопок за наданим зразком.

## Запуск

Node.js **22.22 або новіший** (під час розробки: 24.13.0).

```sh
npm ci
npm run dev
```

У PowerShell із забороненими скриптами використовуйте `npm.cmd` замість `npm`.

```sh
npm run lint
npm run build
npm run preview
```

## Реалізовано

- Додавання: назва, опис, категорія, пріоритет і колір категорії.
- Перевірка обов’язкової назви та пробілів, очищення форми після додавання.
- Виконання, повернення у невиконані та видалення.
- Три фільтри стану, лічильники й автоматична статистика.
- Окремі повідомлення для порожнього списку та результату фільтра.
- Усі шість додаткових пунктів: пошук за назвою, сортування за пріоритетом у двох напрямках, лічильники фільтрів, очищення виконаних, вибір кольору категорії, темна тема.
- Підписи полів, клавіатурний фокус, повідомлення `role="status"`.

Дані й тема зберігаються лише у React state та скидаються після перезавантаження, як передбачено лабораторною. Router, Context, localStorage та глобальні менеджери стану не використовуються.

## Структура

```text
src/
  components/
    Header.tsx       # назва та перемикач теми
    TaskForm.tsx     # поля, валідація, callback додавання
    TaskStats.tsx    # похідна статистика та прогрес
    TaskFilters.tsx  # фільтри, пошук, сортування
    TaskList.tsx     # map, стабільні key, порожні стани
    TaskItem.tsx     # завдання, checkbox, видалення
  data/initialTasks.ts
  types/task.ts
  styles/           # SCSS за логічними BEM-блоками
  App.tsx           # спільний useState, props і callbacks
  main.tsx
```

Статистика обчислюється з поточного масиву, без окремих state-лічильників. Додавання використовує spread, перемикання — `map`, видалення — `filter`. Нові завдання отримують `crypto.randomUUID()`. Сортування застосовується до нового масиву після `filter` і не мутує вихідні дані.

## Демонстрація

1. Надіслати порожню назву або пробіли: відображається помилка.
2. Додати завдання зі своїм кольором і пріоритетом: форма очищується.
3. Перемкнути checkbox, перевірити фільтри й статистику.
4. Знайти назву, перевірити сортування та порожній результат.
5. Очистити виконані, видалити решту й перевірити порожній список.
6. Перемкнути тему, перевірити мобільний екран і клавіатуру.
