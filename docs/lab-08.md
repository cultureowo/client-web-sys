# Лабораторна №8: відповіді на контрольні запитання

1. **Компонент** — функція, яка описує частину інтерфейсу. Компоненти розділяють відповідальність і дозволяють повторне використання.
2. **JSX** — синтаксис JavaScript для опису розмітки. На відміну від HTML використовує `className`, обробники-функції, JS-вирази й компоненти. TSX додає перевірку типів.
3. Один кореневий елемент або Fragment дозволяє повернути один вираз із функції. Fragment групує сусідів без зайвого DOM-вузла.
4. JavaScript-вираз вставляють у фігурних дужках: `<span>{tasks.length}</span>`.
5. **Props** — вхідні дані компонента, які батьківський компонент передає атрибутами, наприклад `<TaskStats total={tasks.length} completed={completed} />`.
6. Дочірній компонент не змінює props напряму. Він викликає callback, наприклад `onToggle(task.id)`, а батьківський компонент оновлює стан.
7. `useState` зберігає стан між рендерами й повертає поточне значення та setter: `const [tasks, setTasks] = useState(initialTasks)`.
8. Пряма мутація зберігає старе посилання, може не спричинити очікуваний рендер і порушує попередні знімки стану. Треба створювати нові масиви й об’єкти.
9. `setState(value)` задає наступне значення. `setState(prev => ...)` обчислює його з попереднього стану в черзі оновлень і потрібне, коли нове значення залежить від старого.
10. `map` перетворює кожен об’єкт на React-елемент. Приклад у `TaskList`: `tasks.map(task => <TaskItem key={task.id} ... />)`.
11. `key` допомагає React зіставляти елементи між рендерами. Індекс змінюється при видаленні або сортуванні та може прив’язати локальний стан до іншого елемента. Використано стабільний `id`.
12. Умовний рендеринг показує різний UI залежно від даних. Варіанти: `if`, тернарний оператор, `&&`. Приклади: порожній список, помилка валідації, позначка виконання.
13. State — пам’ять компонента, якою він керує через setter. Props — дані від батьківського компонента, доступні лише для читання.
14. Спільний стан піднімають до найближчого спільного батьківського компонента. Масив у `App` потрібен формі, списку, фільтрам і статистиці.
15. Setter ставить оновлення в чергу; React повторно викликає компонент із новим станом та оновлює відповідні частини DOM. Значення у поточному обробнику залишається знімком поточного рендеру.
16. Кількість виконаних — похідне значення: `tasks.filter(task => task.completed).length`. Окремий state дублював би дані й міг розсинхронізуватися.
17. **Immutable update** — нове значення без мутації попереднього. Приклади: `[newTask, ...prev]`, `prev.map(...)`, `prev.filter(...)`.
